NARADA AI — Complete PRD v3.0
“The Divine Voice Guide for Digital Journeys”
0. PRODUCT ONE-LINER

Narada AI is a voice-based website guide that understands user behavior, listens to speech, reads page context, and guides visitors through digital journeys using contextual AI + UI highlights + voice narration — embeddable with one script.

Narada = the cosmic messenger in Indian mythology → perfect metaphor.

1. PRODUCT SUMMARY

Narada AI is a two-part system:

🔹 A) Control Plane (Dashboard)

A React-based web app where businesses:

Create an AI voice agent

Add knowledge (Q&A, later PDFs, crawler)

Define Event Tags (sections/elements to track)

Create Journeys / Guided Flows

Configure voice style

Generate embed snippet

View analytics, transcripts, and leads

🔹 B) Runtime Widget (Embeddable Snippet)

A lightweight script installed on any website:

<script src="https://cdn.narada.ai/embed.js" 
        data-agent-id="narada_123"
        async></script>


The widget:

Loads <NaradaWidget /> dynamically

Tracks event tags (view, click, scroll, custom)

Collects context

Handles voice input/output

Connects to backend via WebSocket

Receives agent actions (start flow, highlight, etc.)

Runs Joyride for guided steps

Displays responses in voice + bubble UI

🎯 4.2 Event Tagging System (Critical for Context)

Event Tags allow Narada to understand the user’s journey.

Tag Model:
{
  "id": "pricing_section",
  "label": "Pricing Section",
  "selector": "#pricing",
  "eventType": "view" | "click" | "scroll" | "custom",
  "pagePattern": "/pricing"
}

Defined by company in dashboard.
Detected by widget using:

IntersectionObserver

Click listeners

Scroll listeners

Manual triggers

Sent to backend in context:
"context": {
  "url": "/pricing",
  "lastTag": "emi_opened",
  "recentTags": [
    {"tagId": "pricing_viewed", "type": "view"},
    {"tagId": "emi_opened", "type": "click"}
  ]
}


Narada uses this for hyper-contextual responses.

🌐 4.3 Journeys & Guided Flows (Joyride)

A Journey = set of Steps with UI highlights.

Flow Model:
{
  "id": "emi_flow",
  "agent_id": "narada_123",
  "name": "EMI Flow",
  "page_url": "/pricing"
}

Step Model:
{
  "id": "emi_step_1",
  "flow_id": "emi_flow",
  "selector": "#emi-calculator",
  "title": "EMI Calculator",
  "tooltip_text": "This helps calculate monthly payments.",
  "voice_script": "Let me show you how EMI works.",
  "order": 1
}

When AI triggers:
{
  "type": "agent_response",
  "replyText": "...",
  "action": { "type": "start_flow", "flowId": "emi_flow" }
}


Widget:

Loads steps

Starts Joyride

Emits additional tag events

Maintains progress

🔊 4.4 Voice Pipeline (OpenAI Realtime API)

Narada uses:

PRIMARY ENGINE: OpenAI Realtime API

Provides:

Real-time STT

Function calling (agent tools)

Realtime response generation

Realtime TTS output

Low latency

Natural turn-taking

Interruptions

Exactly what Narada needs.

Tools passed to OpenAI Realtime:
{
  "start_flow": { "flowId": "string" },
  "go_to_step": { "stepId": "string" },
  "tag_event": { "tagId": "string" },
  "capture_lead": { "name": "string", "phone": "string" }
}

🔥 Optional: ElevenLabs Premium Voice Mode

For enterprise customers:

Use OpenAI Realtime for reasoning
